## setup

```bash
git clone https://github.com/lostf1sh/lostf1sh.github.io
cd lostf1sh.github.io
bun install
bun run dev
```

## scripts

```bash
bun run dev      # start vite dev server
bun run build    # build site + seo assets
bun run preview  # preview production build
```
